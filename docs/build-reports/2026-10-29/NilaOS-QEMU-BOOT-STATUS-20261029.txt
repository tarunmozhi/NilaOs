LIMITATIONS
- The userspace console still reports "Warning: unable to open an initial console"; initramfs output/rescue shell is not yet verified.
- The initramfs currently waits for a separate filesystem labeled NILA_ROOTFS. That root filesystem has not been attached in this test, so this is not a complete OS boot.
- This kernel is a QEMU-specific test build. It contains CONFIG_NILA_QEMU_TEST-only bypasses for Qualcomm secure-monitor calls and Vivo SMEM board info, to let generic QEMU hardware get past phone-specific early init.
- It is NOT a flash-ready Vivo Y11 ROM and must NOT be flashed to the phone.
- The original kernel source files were restored after the test-only build changes; a search found no remaining CONFIG_NILA_QEMU_TEST markers in the edited Qualcomm/Vivo source directories.
- No phone was flashed or modified.
